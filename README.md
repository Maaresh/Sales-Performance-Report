# Sales Performance Report | Power BI

## Project Overview

This project presents a sales performance analysis and interactive dashboard developed using Microsoft Power BI.

The dashboard is designed to analyze sales performance and present key business metrics through interactive visualizations.

## Objectives

- Analyze sales performance
- Track key performance indicators
- Identify sales trends
- Compare business performance
- Create an interactive reporting dashboard
- Present insights through data visualization

## Tools Used

- Microsoft Power BI
- Power BI Desktop
